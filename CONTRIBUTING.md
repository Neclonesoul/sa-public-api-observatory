# Contributing

Submit candidates as YAML under `catalogue/candidates/`. Include publisher, official documentation, endpoint, proposed universe, publisher class, access class, authentication, licence evidence, discovery source and evidence URLs.

Lifecycle: `discovered → triage → verification-required → verified | rejected | duplicate | retired`.

Promotion requires review. A candidate cannot activate monitoring. CI runs type checks, tests, catalogue validation, URL safety checks and the production build. Do not submit credentials, private endpoints, destructive operations or personal data.
